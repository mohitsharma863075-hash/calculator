#WrongCalc — A fun entertainment calculator that intentionally generates incorrect answers with a free trial, subscription plans, Card/UPI payment demo, and Premium unlock system.

GitHub About / README Description

WrongCalc is a fun and experimental calculator web app that intentionally generates incorrect mathematical answers for entertainment purposes. The project includes a one-time free calculation, subscription plans, Card/UPI payment UI, demo payment processing, payment success/failure screens, Premium activation, calculation history, and persistent subscription state using LocalStorage.

⚠️ Disclaimer: WrongCalc intentionally provides incorrect results and should never be used for real mathematical, financial, scientific, medical, engineering, or educational calculations.
